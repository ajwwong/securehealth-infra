# Practice Harbor embeddable widget (`booking.js`)

Third-party-site embed script served from `https://widget.practiceharbor.com/booking.js`.
It mounts a button into every element carrying `data-ph-widget` (or the legacy id
`#ph-booking-widget`); clicking the button opens the practice's booking or contact page
(`https://{slug}.securehealth.me/book|/contact?embed=true`) in a full-screen overlay iframe.

The user-facing snippet is generated by `progress2-base/src/pages/settings/WidgetSettings.tsx`
(`buildEmbedCode`) — keep the attribute contract below in sync with it, and with the help-center
page `docs-site/docs/scheduling/online-booking.md`.

## Attribute contract

| Attribute | Required | Meaning |
|---|---|---|
| `data-ph-widget` | yes* | Mount marker. (*The ids `ph-booking-widget` / `ph-contact-widget` also work; `data-ph-widget` is what the script actually selects on, so multiple widgets per page are supported.) |
| `data-slug` | yes | Practice portal slug. Becomes the iframe hostname label, so it is validated as a DNS label (`^[a-z0-9-]{1,63}$`); the widget silently does not mount otherwise. |
| `data-type` | no | `contact` opens `/contact` instead of `/book`. |
| `data-practitioner` | no | Practitioner id appended to the booking URL (ignored for contact). |
| `data-button-text` | no | Button label. Defaults: "Request Appointment" / "Contact Us". |
| `data-button-color` | no | Button background. Validated as a hex value or bare CSS color keyword (it is concatenated into `cssText`); anything else falls back to the default `#228be6`. |

## Events / messaging

- The embed pages post `{type: 'ph-widget-close'}` / `{type: 'ph-widget-complete'}` to the
  parent; origins are checked against `\.securehealth\.me$`.
- On complete, the script closes the overlay and dispatches a bubbling `ph-booking-complete`
  CustomEvent on the mount element, so host sites can hook conversion tracking.

## Accessibility (do not regress)

The overlay is a modal dialog: `role="dialog"`, `aria-modal="true"`, `aria-label`, a titled
iframe, initial focus on the labeled close button, a focus trap (Shift+Tab from the close
button wraps to the iframe; focus landing outside the overlay is pulled back), Escape-to-close,
and focus restored to the triggering element on close. Verified with a Playwright script that
drives a host page embedding this file — re-run something equivalent after editing.

## Deploy

```bash
aws s3 cp widget/booking.js s3://widget.practiceharbor.com/booking.js \
  --content-type 'application/javascript' --cache-control 'public, max-age=3600'
aws cloudfront create-invalidation --distribution-id E3MEU1YB0A4AKC --paths '/booking.js'
```

Verify with a string literal from the change:
`curl -s https://widget.practiceharbor.com/booking.js | grep aria-modal`
